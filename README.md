# 🚀 Portfolio Website

A personal portfolio website built to showcase my projects, technical skills, experience, and background as a Computer Science student.

The website focuses on a clean and modern interface, responsive design, smooth interactions, and real-world software development projects.

## ✨ Features

* Fully responsive design for desktop, tablet, and mobile
* Interactive project showcase
* Experience and education sections
* Technical skills overview
* Smooth scrolling and animations
* Scroll-based effects using the Intersection Observer API
* Custom UI components built with vanilla HTML, CSS, and JavaScript
* Direct links to GitHub, LinkedIn, and email
* Optimized layout for readability and performance

## 🛠 Tech Stack

* **HTML5** – Website structure and semantic markup
* **CSS3** – Styling, animations, responsive layouts, and custom UI
* **JavaScript** – Interactivity and dynamic behavior
* **Intersection Observer API** – Scroll-triggered animations and effects
* **Responsive Design** – Mobile, tablet, and desktop support

## 📱 Responsive Design

The portfolio is designed to work across different screen sizes, including:

* Desktop
* Laptop
* Tablet
* Mobile

Layouts, typography, navigation, images, and project sections automatically adapt based on screen size.
